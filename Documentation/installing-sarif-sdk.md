Installing Sarif-SDK

	To install Sarif Sdk on your machine, first download and install dotnet sdk: https://dotnet.microsoft.com/download/dotnet/2.1

	Then install the latest version of Sarif Sdk https://www.nuget.org/packages/Sarif.Sdk/. You can also use this command after installing dotnet: dotnet add package Sarif.Sdk --verison 2.4.10. 

- Once installation is successful, add .dotnet\tools to PATH (if it's not already there) as that's where the tool goes if installed using the command above. After that check installation by running 		sarif multitool commands like the one shown in sarif-tool-check.png
